## 4. Review repository descriptions

Use one sentence per repository in the About description. Lead with the method and financial problem, for example: "PCA-based cross-sector residual mean-reversion research with chronological out-of-sample backtesting."

## 5. Avoid misleading profile signals

- Do not add a project result or speed-up claim unless the exact experiment, hardware, and test setup are documented.
- Avoid skill bars or percentage ratings; they do not communicate technical depth.
- Do not use commit frequency as a proxy for research quality.
- Add contact links only after confirming the public URLs you want to share.
